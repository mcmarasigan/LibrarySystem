# 📚 Library Management System

A Python-based Library Management System designed to automate and streamline library operations.  
This project was developed as part of an academic requirement to demonstrate modular programming and basic GUI development in Python.

---

## ✨ Features
- **Book Management** – Add, update, and remove book records  
- **Borrowers Management** – Track borrower details and accounts  
- **Circulation** – Monitor book borrowing and returning processes  
- **Search Module** – Search and filter books in the catalog  
- **Sentiment Analysis** – Basic NLP feature for analyzing feedback/reviews  
- **Graphical User Interface** – Built using Qt Designer (`.ui` file)  

---

## 🛠 Technologies Used
- **Python 3.x** – Core programming language  
- **PyQt / Qt Designer** – For graphical user interface (`.ui` file)  
- **NLTK / TextBlob (or similar)** – For sentiment analysis  
- **File-based storage** – For saving and retrieving records
